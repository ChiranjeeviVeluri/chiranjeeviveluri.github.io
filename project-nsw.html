The Short Version

The question

How do location, socio-economic profile and property type drive housing prices across NSW?

What I did

Cleaned 2.2M government sale records in Python, enriched them with ABS SEIFA indexes, modelled a MySQL star schema and built a two-page Power BI dashboard.

03 — Methodology

How It Was Done

Five steps. Select one to see the detail.

01

Data Sourcing & Cleaning

Loaded 2,206,232 raw records and resolved seven real data-quality issues, including 560,545 duplicate rows, mixed price scales, mixed land-area units, and inconsistent property-type labels.

02

Socio-Economic Enrichment

Joined all four ABS SEIFA 2021 indexes onto the cleaned sales data by postcode — a 100% match rate across every NSW postcode.

03

Relational Warehouse Design

Normalised the data into a MySQL star schema: a fact_property_sales table referencing a dim_postcode_seifa dimension table.

04

Analytical SQL

LAG for year-over-year growth, NTILE for price quartiles, and suburb-relative outlier detection.

05

Interactive Power BI Dashboard

Connected Power BI to the MySQL warehouse and built a DAX measure library across a two-page overview and suburb drill-down.

04 — Key Findings
